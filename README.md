# Фокус-таймер

Небольшое браузерное приложение для Pomodoro-сессий. Работает без фреймворков и сторонних зависимостей.

## Возможности

- сессии на 15, 25 или 45 минут;
- старт, пауза, продолжение и сброс;
- выбранная задача и дневная статистика сохраняются только в `localStorage`;
- управление стартом и паузой через пробел;
- адаптивный интерфейс и поддержка `prefers-reduced-motion`.

## Запуск

Требуется Node.js 20 или новее.

```bash
npm start
```

Откройте <http://127.0.0.1:4173>.

## Проверки

```bash
npm test
npm run check
```
